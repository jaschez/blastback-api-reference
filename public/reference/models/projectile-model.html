ProjectileModel

Defines projectile behavior, physics, and collision for ranged weapons.

Model

Schema

JSON
{
  "velocity": 200.0,
  "damage": 10,
  "maxHitNumber": 1,
  "maxBounces": 0,
  "velocityDecrease": 0.0,
  "killingVelocity": 0.0,
  "rotationVelocity": 0.0,
  "verticalSize": 4.0,
  "horizontalSize": 4.0,
  "isEnemyBullet": false,
  "collectable": false,
  "bounceOffMobs": false,
  "ignoreAttackHimself": true,
  "special": false,
  "overridingCollisionMask": 0,
  "effects": [...]
}

Description

The ProjectileModel defines the complete behavior of projectiles fired by ranged weapons. It covers velocity, damage, hitbox sizing, bounce mechanics, hit limits, collection, and visual effects. Projectiles use physics layer 4 by default and interact based on their collision mask.

Fields

NameTypeDescription
velocityfloatMovement speed of the projectile.
damageintDamage dealt per hit.
hitNumberintCurrent hit count (runtime state).
maxHitNumberintMaximum number of hits before the projectile is destroyed. Use higher values for piercing.
maxBouncesintMaximum number of times the projectile can bounce off surfaces.
velocityDecreasefloatSpeed lost per bounce. The projectile slows after each bounce.
killingVelocityfloatMinimum velocity required for the projectile to deal damage. Below this, the projectile is inert.
rotationVelocityfloatVisual rotation speed of the projectile sprite.
verticalSizefloatVertical hitbox size.
horizontalSizefloatHorizontal hitbox size.
triggerStepOffsetfloatTrigger offset per physics step for collision detection.
isEnemyBulletboolIf true, this is an enemy projectile (damages the player).
collectableboolIf true, the projectile can be picked up after landing.
bounceOffMobsboolIf true, the projectile bounces off mobs instead of being destroyed on hit.
ignoreAttackHimselfboolIf true, the projectile cannot damage the entity that fired it.
specialboolFlags the projectile as special (used for unique gameplay mechanics).
overridingCollisionMaskintCustom collision layer mask. Overrides default projectile collision when non-zero.
effectsProjectileEffect[]Array of effects applied on hit, bounce, or destruction.

Example

JSON — Bouncing ball projectile
{
  "velocity": 180.0,
  "damage": 15,
  "maxHitNumber": 3,
  "maxBounces": 5,
  "velocityDecrease": 20.0,
  "killingVelocity": 40.0,
  "rotationVelocity": 8.0,
  "verticalSize": 6.0,
  "horizontalSize": 6.0,
  "isEnemyBullet": false,
  "collectable": true,
  "bounceOffMobs": true,
  "ignoreAttackHimself": true
}
