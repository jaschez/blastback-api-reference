ParticleSpawnModel

Defines particle emission properties for visual effects.

Model

Schema

JSON
{
  "particleType": "spark",
  "count": 10,
  "speed": 5.0,
  "spread": 45.0,
  "lifetime": 0.8
}

Description

The ParticleSpawnModel defines how particles are emitted for visual effects in the Blastback Engine. It controls the type of particle to spawn, the number of particles per emission, their movement speed, angular spread, and how long each particle lives before being destroyed. This model is used to create effects such as explosions, bullet impacts, muzzle flashes, and environmental ambiance.

Fields

NameTypeDescription
particleTypestringThe type identifier of the particle to emit. Must match a registered particle type (e.g., "spark", "smoke", "blood").
countintThe number of particles to spawn per emission burst.
speedfloatThe initial movement speed of each spawned particle in units per second.
spreadfloatThe angular spread in degrees over which particles are emitted. A value of 360 emits in all directions.
lifetimefloatThe duration in seconds each particle exists before being destroyed.

Example

JSON
{
  "particleType": "explosion_debris",
  "count": 25,
  "speed": 8.0,
  "spread": 360.0,
  "lifetime": 1.2
}
