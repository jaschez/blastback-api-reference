UI Entity

Base UI entity component that marks an entity as belonging to the UI rendering layer.

Component UI

Schema

JSON
"uiEntity": {
  "layer": 0,
  "anchor": "...",
  "visible": true
}

Description

The UIEntity component designates an entity as a UI element, placing it in the UI rendering layer separate from the game world. It controls the base properties of any UI element including its rendering layer order, screen anchor position, and visibility. All UI components require a UIEntity component as their foundation.

Fields

NameTypeDescription
layerintThe rendering layer order. Higher values render on top of lower values.
anchorstringScreen anchor position (e.g., "topLeft", "center", "bottomRight").
visibleboolWhether the UI entity is currently visible.

Example

JSON
{
  "components": {
    "uiEntity": {
      "layer": 10,
      "anchor": "topLeft",
      "visible": true
    }
  }
}
