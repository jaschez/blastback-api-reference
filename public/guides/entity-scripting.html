Entity Scripting

Learn how to create entities, attach components, and script behaviors using the Blastback Engine's data-driven system.

Creating an Entity

Every entity in Blastback is defined as a JSON file. The file name determines the entity's type identifier, and a suffix determines its model category (e.g., enemy_slime.mob.json for a mob entity).

enemy_slime.mob.json
{
  "name": "Slime",
  "visualsPath": "enemies/slime",
  "renderLayer": 5,
  "colliderSizeX": 12,
  "colliderSizeY": 10,
  "physicsLayer": 3,
  "collisionLayerMask": [1, 2, 4],
  "components": {
    "animator": {
      "triggers": {
        "idle": {},
        "walk": {},
        "attack": {
          "hit": 4
        }
      }
    },
    "ai": {
      "templateID": "basic_chase"
    },
    "mob": {
      "health": 30,
      "damage": 10
    },
    "movement": {
      "speed": 60.0
    }
  },
  "model": {
    "id": "slime_basic",
    "namespc": "enemies"
  }
}

The Component System

Components are the building blocks of entity behavior. Each component is added to the components dictionary with a string key (the component type) and a configuration object.

Note
All components inherit a base commandMap field that maps event names to command strings, providing a flexible event-driven architecture.
Component with commandMap
"components": {
  "trigger": {
    "commandMap": {
      "onPlayerEnter": "entity.emit alert",
      "onDamaged": "entity.animate hurt,once"
    },
    "events": {
      "onCollision": ["onPlayerEnter"]
    }
  }
}

Events & Commands

Blastback uses an event-driven architecture. Entities can emit and listen to events, and commands can be triggered in response.

Built-in Entity Events

EventDescription
entity.onStartFires when the entity is added to the world.
entity.onVisibleFires when the entity becomes visible.
entity.onDestroyFires when the entity is destroyed.

Built-in Entity Functions

entity.emit <eventID>Function

Emits a custom event with the specified ID. Other components listening for this event will be notified.

ParameterTypeDescription
eventIDstringThe identifier of the event to emit.
entity.animate <animationName>,<loopMode>Function

Plays an animation on the entity. An alternative to using the animator component for simple one-off animations.

Physics Configuration

Entities can have physical properties by adding physics extension fields directly in the entity JSON definition.

FieldTypeDescription
colliderSizeXintWidth of the entity's collider.
colliderSizeYintHeight of the entity's collider.
isTriggerboolIf true, collider acts as a trigger zone (no physical blocking).
physicsLayerintThe entity's physics layer identity.
collisionLayerMaskint[]Which physics layers this entity can interact with.

Physics Layer Reference

LayerIDUsage
Tilemap1World geometry and tiles
Player2Player entities
Enemy3Enemy/hostile entities
Projectile4Bullets and projectiles
Weapon5Weapon entities
Props6Destructible and interactive props
Drop7Item drops and pickups
Melee Impacts8Melee attack hit zones
Particle10Visual particle effects
Tip
Set collisionLayerMask to only include layers the entity actually needs to interact with. For example, an enemy projectile typically only needs [1, 2] (Tilemap and Player).

Complete Entity Example

Here's a complete example of a ranged enemy entity with AI, animations, and a weapon:

enemy_archer.mob.json
{
  "name": "Skeleton Archer",
  "visualsPath": "enemies/skeleton_archer",
  "renderLayer": 5,
  "colliderSizeX": 14,
  "colliderSizeY": 20,
  "physicsLayer": 3,
  "collisionLayerMask": [1, 2, 4, 5],
  "components": {
    "animator": {
      "triggers": {
        "shoot": { "release": 6 },
        "death": { "drop": 3 }
      }
    },
    "ai": {
      "templateID": "ranged_attack",
      "resolution": {
        "attackAction": {
          "commands": [
            "entity.animate shoot,once"
          ]
        }
      }
    },
    "mob": {
      "health": 45,
      "damage": 15,
      "invincibilityTime": 0.3
    },
    "movement": {
      "speed": 40.0
    },
    "weaponHandler": {}
  },
  "model": {
    "id": "skeleton_archer",
    "namespc": "enemies",
    "animation": {},
    "events": {
      "animator.shoot.release": {
        "fireWeapon": {}
      },
      "animator.death.drop": {
        "spawnDrop": {}
      }
    }
  }
}
